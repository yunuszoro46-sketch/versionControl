# Git Learning & Version Control Practice

A practice repository created on Ubuntu to learn basic Git concepts, workflow, and terminal commands.

## Topics Covered
* Initializing a Git repository (`git init`)
* Checking repository status (`git status`)
* Tracking and staging changes (`git add`)
* Committing snapshots locally (`git commit`)
* Connecting to remote repositories on GitHub (`git remote add`)
* Pushing local commits to GitHub (`git push`)

## Prerequisites
* Linux/Ubuntu terminal environment
* Git installed (`git --version`)
* A GitHub account and Personal Access Token (PAT) for HTTPS authentication
